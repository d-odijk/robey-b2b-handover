Using the prototype

  • Resize the window: mobile (< 768), tablet portrait (768–899), tablet landscape (900–1199) and desktop (≥ 1200) are one file. The indicator bottom-right names the breakpoint.
  • Everything that looks clickable works: menu, search, filters, colour swatches, the size matrix (type quantities), the cart, the account pages, the gallery view.
  • Quantities typed on a product page appear in the cart immediately; there is deliberately no "Add to cart" button.
  • Sample data, not authoritative. The on-screen copy is Dutch: the portal is for Dutch customers, and the wording is part of the design.

Reading values

The prototype is real HTML and CSS, so the browser inspector replaces a design tool's inspect panel: right-click, Inspect, and you get the real spacing, font sizes, colours and hover behaviour per breakpoint. Classes are named rb-<component>__<part> (glossary in the dossier) and the values refer to the tokens.

Adopt the values, the structure of each component, the behaviour and the copy. Do not adopt the prototype's own code: it is generated design code with a single DOM and embedded images; the portal gets components with props and data from the Storefront and Customer Account APIs.
